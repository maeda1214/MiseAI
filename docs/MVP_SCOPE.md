# MVP Scope

Build only the following for v0.1.

## Included
1. Email/password signup and login
2. Industry selection
   - Beauty salon
   - Restaurant
3. Business information form
4. Industry-specific form fields
5. Photo upload
   - Minimum 10 required before generation
6. AI content generation
   - business description
   - section copy
   - FAQ draft
   - SEO title
   - meta description
7. Generate 3 design variants
8. Preview all 3
9. Select one design
10. Edit content before publish
11. Publish one-page site
12. Free subdomain
13. Public photo gallery
14. Click/tap to enlarge image
15. LINE reservation CTA
16. Restaurant external reservation links
17. Restaurant tap-to-call CTA
18. Dashboard
19. Publish/unpublish
20. Stripe paid support plan
21. Support request form
22. Count support requests per billing month
23. Flag 11th+ requests as extra-charge eligible

## Excluded from first MVP
- Automatic LINE message ingestion
- GMO direct debit
- Complex team accounts
- Native mobile app
- AI image generation
- Full Google Business Profile API integration
- Automatic AdSense onboarding
- Affiliate network automation
- Multi-language
- Advanced analytics
- Automatic custom-domain DNS configuration
- WYSIWYG drag-and-drop page builder
